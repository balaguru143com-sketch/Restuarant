ROYAL TASTE – MULTI-PAGE RESTAURANT WEBSITE
================================================

Pages
-----
1. index.html        Home
2. menu.html         Menu
3. special-menu.html Special Menu
4. about.html        About
5. contact.html      Contact

How to run
----------
- Extract the ZIP file.
- Open index.html in a browser, or use VS Code Live Server.
- All pages share styles.css and script.js.

SEO included
------------
- Unique SEO title and meta description on every page.
- Page-specific keyword meta tags (supporting metadata only; Google does not use meta keywords as a ranking signal).
- One clear H1 per page and structured H2/H3 headings.
- Descriptive image alt text.
- Canonical URLs (replace example.com with your real domain).
- Open Graph metadata.
- Restaurant JSON-LD schema on the home page.
- robots.txt and sitemap.xml.
- Internal navigation links and responsive layout.

IMPORTANT CUSTOMISATION BEFORE LAUNCH
-------------------------------------
1. Replace Royal Taste with the real restaurant name if different.
2. Replace example.com in canonical tags, sitemap.xml and robots.txt.
3. Add the real address, phone, email, opening hours and city on contact.html.
4. Update Restaurant schema address and telephone in index.html.
5. Replace sample menu items/prices and demo content with real details.
6. Add a real Google Maps embed on contact.html.
7. Connect the contact form to a backend or form service. It is currently front-end demo only.
8. Replace image URLs if you have licensed restaurant photography. Images load from Unsplash and require internet access.

Local SEO:
Add your actual city/neighbourhood naturally to page titles, descriptions and useful page copy only after confirming the real business location. Do not use an inaccurate location keyword.

Note:
The meta keywords tag is retained as a project/demo field, but Google Search does not use it for ranking. Prioritise useful content, title tags, internal links, page speed, accurate business details and genuine local relevance.
